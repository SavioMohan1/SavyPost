Quick Channel Setup Guide

Telegram (1 Min Setup)

1. Message @BotFather on Telegram & send /newbot.
2. Copy HTTP API Token.
3. Add bot as Admin to your channel, and set Chat ID to @channelname.

Discord (30 Sec Setup)

1. Open Discord Channel Settings → Integrations.
2. Click Webhooks → New Webhook.
3. Copy Webhook URL and paste into Token.

Bluesky (AT Protocol)

1. In Bluesky, go to Settings → App Passwords.
2. Click Add App Password.
3. Paste password into Token and your handle into Username.
